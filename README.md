Faster drop-in for makefun-site 1.0.0: a static site generator that answers byte-identical to the reference and runs about 39% faster on the practice set. `solve.js` is a dependency-free ES module whose `run(input)` returns the output tree for a generated site; `main.ts` reads every case from `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
